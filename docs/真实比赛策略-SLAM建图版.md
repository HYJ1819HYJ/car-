## 🔧 完整的SLAM建图+导航流程

### 阶段 1：建图（5-8分钟）

**启动命令：**
```bash
roslaunch maze_bridge gmapping_build_map.launch show_rviz:=true
```

**你的操作：**
1. 启动程序后，用蓝牙手柄或遥控让小车运动
   - 目标：让小车走遍整个迷宫，获取完整的环境信息
   - 建议：走个"之字形"或"螺旋形"确保覆盖全场

2. 观察RViz中的地图显示
   - 绿色区域 = 已探索的开放空间
   - 黑色/灰色区域 = 障碍物
   - 黄色点 = 激光扫描数据

3. 地图生成到：`~/.ros/maze_map.yaml`（和 maze_map.pgm）

4. 停止程序（Ctrl+C）

### 阶段 2：导航（5分钟以内）

**启动命令：**
```bash
roslaunch maze_bridge navigation_stack.launch mode:=navigation
```

**系统自动做的事：**
- 加载已建立的地图
- 启动AMCL定位（用激光雷达定位小车位置）
- 启动move_base导航规划

**你的操作：**
1. 看到RViz打开，显示已建立的地图和小车位置
2. 在RViz中点击"2D Nav Goal"工具
3. 在地图上点击终点位置（黄色区域的中心）
4. move_base会自动规划路径并执行导航
5. 小车沿着规划的路径走向终点
6. 到达终点后，自动停止（或手动停止）

## 🔨 关键参数调优

### Gmapping参数（在 gmapping_build_map.launch 中）

**如果建图太差（地图不清晰）：**
```xml
<!-- 增加粒子数量 -->
<param name="particles" value="100"/>  <!-- 原值: 30 -->

<!-- 减少地图更新间隔，更快响应 -->
<param name="map_update_interval" value="1.0"/>  <!-- 原值: 2.0 -->
```

**如果建图太慢（计算量过大）：**
```xml
<!-- 减少粒子数量 -->
<param name="particles" value="15"/>  <!-- 原值: 30 -->
```

### Move_base参数（自主导航）

**如果小车走得太快，容易撞到障碍物：**
```bash
# 在导航过程中，move_base的局部规划器会自动减速
# 如果需要手动调整，修改：
dwa_local_planner_params.yaml
# max_vel_x: 0.3  # 改小一点，比如 0.2
```

**如果小车行动太慢：**
```bash
# 增加最大速度
dwa_local_planner_params.yaml
# max_vel_x: 0.5
```

## ⚠️ 常见问题与解决

### Q1: 建图时地图显示为全黑或全白？
**A:** 
- 检查激光雷达是否工作：`rostopic echo /scan | head -5`
- 检查TF树是否正确：`rosrun tf view_frames`
- 如果激光雷达无数据，检查硬件连接

### Q2: 导航时小车不动？
**A:**
- 检查地图是否被正确加载：RViz中应该看到灰黑色的地图
- 检查目标点是否设置在可行走区域（绿色区域）
- 检查move_base是否启动：`rosnode list | grep move_base`

### Q3: 小车经常撞到障碍物？
**A:**
- 增加局部规划器的安全距离
- 编辑 `dwa_local_planner_params.yaml`
- 增加 `inflation_radius` 值

### Q4: 建图时间太长？
**A:**
- 减少粒子数量（particles）
- 但这会牺牲精度
- 权衡：精度 vs 速度

### Q5: 建图精度不够？
**A:**
- 增加粒子数量
- 放慢小车运动速度（让激光雷达有时间扫描）
- 走得更均匀，避免急转弯

## 💡 比赛日策略

### 你需要理解的流程

```
比赛开始（20分钟计时）
    ↓
[建图阶段] 你操控小车
    ↓
  6-8分钟后，地图建立完成
    ↓
[固定障碍物确认] 裁判确认
    ↓
[加入动态障碍物] 裁判添加（位置随机！）
    ↓
[第1次导航] 你设定终点（在地图上点击）
    ↓
  小车自主导航到终点（最多5分钟）
    ↓
  成功？→ 记录时间 → 比赛结束
  失败？→ 重试第2、3次
    ↓
[时间到] 20分钟结束
```

### 关键决策

**建图时的操作策略：**
1. 让小车走遍整个迷宫
2. 特别注意起始线到终点线的中间路径
3. 让激光雷达看到所有的固定障碍物
4. 建议速度：0.2 m/s（慢一点，确保扫描质量）

**导航时的操作策略：**
1. 根据当前的终点位置，点击RViz中相应位置
2. move_base会自动规划并执行
3. 如果卡住或走错路，停止并重试
4. 还有2次重试机会

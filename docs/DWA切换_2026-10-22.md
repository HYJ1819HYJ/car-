# asuka_dwa 局部规划切换

本地分支 `asuka_dwa` 从 `asuka-main` 创建，保留创建时已有的仿真、地图和工具修改。实车和 Stage 默认均使用 `dwa_local_planner/DWAPlannerROS`；本说明取代旧文档中的 TEB 参数、话题和 `forward_only_local_planner` 启动参数。分支创建本身不代表已提交或推送。

## 配置入口

- `src/maze_bridge/launch/dwa_local_planner_params.yaml`：DWA 采样、速度、加速度、目标容差和代价权重。
- `src/maze_bridge/launch/navigation_stack.launch`：实车导航入口。
- `src/competition_sim/launch/navigation.launch`：Stage 仿真入口。
- `src/maze_bridge/config/footprint_stl.yaml`：共享的 24 点完整 STL 车体轮廓。DWA 从局部 costmap 读取轮廓，无需额外的 `footprint_model`。

实车入口默认线速度上限 0.50 m/s、角速度上限 0.75 rad/s；仿真入口按用户要求改为 3.0 m/s、1.0 rad/s，DWA 与仿真安全层共用上限，Stage 模型同步支持 3.0 m/s、1.0 rad/s。仿真安全层按速度扩展预测区域内的雷达点保留范围，继续保留近障减速、完整轮廓扫掠检查及超时停车。两个入口均可使用 `max_nav_v:=0.10 max_nav_w:=0.25` 降速。线速度参数同时覆盖 DWA 的 `max_vel_x` 和 `max_vel_trans`。`min_vel_x=0` 禁止自主倒车，横向速度为零。目标位置/角度容差均为 0.12，加速度及 DWA 其余采样参数沿用仓库原有 DWA 配置；关闭两项点云诊断发布以减少额外负载。

全局规划仍为 SmoothGlobalPlanner，`smooth_global_plan:=false` 仅切回 GlobalPlanner，局部规划保持 DWA。原有完整车体检查、未知区域策略、地图、墙角/末端保护、独立串口安全门、超时停车与底盘协议保持原有设置。已移除 TEB 专用包装器、配置及依赖。

`twirling_scale` 曾按用户要求从 0 调至 50，对每条候选增加 `50 * abs(w)` 的代价。该项也会惩罚正常前进转弯。卡住位置的静态快照对照中，权重 0～25 仍选零平移小转向，50～1000 切换为约 0.00144 m/s 的直行；因此本次只确认该快照中的选择发生变化，不能认定完整弯道已通过。对照日志在本地 `outputs/dwa_twirling_20261022/probe_result.log`。保存分支时保留最新调参值 `goal_distance_bias=15.0`、`occdist_scale=0.30`、`twirling_scale=1.0`，最新组合尚未验证整段通行。

## 仿真与检查

在宿主机启动独立仿真（Stage 窗口、RViz，默认演示会向虚拟小车发送终点目标）：

```bash
cd '/home/asuka/Desktop/college-level competition/xiaoche'
./start-competition-sim.sh scenario:=01_open demo:=false max_nav_v:=3 max_nav_w:=1
```

此命令手动发目标；自动演示可使用 `demo:=true`。退出时在启动终端按 Ctrl+C，等待仿真节点结束。仿真 master 为 11329，运动只发往 `/simulation/*`，不启动底盘串口或真实雷达。代码修改后需重新编译 `simulation_safety_gate`，并重启仿真让模型和配置生效。

另一个宿主机终端可检查当前插件和上限：

```bash
R1='/home/asuka/Desktop/college-level competition/xiaoche-ros1.sh'
"$R1" env ROS_MASTER_URI=http://127.0.0.1:11329 rosparam get /move_base/base_local_planner
"$R1" env ROS_MASTER_URI=http://127.0.0.1:11329 rosparam get /move_base/DWAPlannerROS/max_vel_x
"$R1" env ROS_MASTER_URI=http://127.0.0.1:11329 rosparam get /move_base/DWAPlannerROS/max_vel_trans
"$R1" env ROS_MASTER_URI=http://127.0.0.1:11329 rosparam get /move_base/DWAPlannerROS/max_vel_theta
```

预期为 `dwa_local_planner/DWAPlannerROS`、`3.0`、`3.0`、`1.0`。局部路径话题为 `/move_base/DWAPlannerROS/local_plan`；RViz、录包工具和仿真统计已同步更新。

参数回归检查不会启动硬件或 ROS 节点：

```bash
R1='/home/asuka/Desktop/college-level competition/xiaoche-ros1.sh'
"$R1" python3 /workspace/xiaoche/tools/test_dwa_configuration.py
```

# 建图墙线重影排查与修复（2026-10-07）

## 结论和修改

同一面墙在转弯后出现多个占用边，属于不同扫描以不一致位姿叠入地图的重影。当前证据支持扫描匹配角度偏差积累是本次的一个可修复因素；没有证据把全部误差归因于轮径或轮距，也没有完成外部测量基准下的完整实车验收。

已修改 `src/maze_bridge/launch/slam_toolbox_params.yaml` 两项：

| 参数 | 原值 | 新值 | 作用 |
|---|---:|---:|---|
| correlation_search_space_smear_deviation | 0.05 m | 0.025 m | 缩窄扫描匹配响应带，减少偏移点仍获较高匹配分数的机会 |
| fine_search_angle_offset | 0.00349 rad | 0.000873 rad | Karto 精匹配角度采样步长由约 0.2° 改为 0.05° |

注意：此版本 Karto 把 `fine_search_angle_offset` 传作精匹配采样步长，精匹配搜索范围为 `coarse_angle_resolution / 2`。这是源码核对结果，不能仅按参数名称理解为搜索范围。源码：<https://github.com/SteveMacenski/slam_toolbox/blob/1.5.7/slam_toolbox/lib/karto_sdk/src/Mapper.cpp>，`ScanMatcher::MatchScan`。

本次未改里程计标定值、雷达外参、车辆尺寸、导航膨胀或底盘安全控制。

## 实车只读证据

- 当前只有 slam_toolbox 建图，没有 AMCL、GMapping、move_base 并行运行；TF 发布链可连接，没有重复的 map→odom / odom→base 发布者。
- 停车 25 秒的扫描约 29.6 Hz，1440 点/帧，时间戳无重复、无倒退。扫描接收年龄平均约 35 ms，最大约 43 ms。
- 停车里程计位置变化约 0.13 mm，角度变化约 0.018°；map→odom 期间未变化。用户确认重影发生在转弯后。
- 实车转弯段分成约 0.27 s 的相邻扫描对，点到线匹配与编码器积分的转角合计分别约 -78.5° 和 -82.4°。独立激光匹配也有累计误差，不能把约 3.9° 的差值直接用于重新标定轮距。
- 初步发现 `shouldProcessScan` 只检查平移，但进一步核对实际异步节点后，确认它没有调用该函数；历史图含小位移转弯扫描。这个假设已排除，相关候选代码已撤回，最终没有替换 SLAM 节点。

## 同数据回放验证

全部回放使用独立 master `127.0.0.1:11315`，只运行 SLAM、数据回放和观察节点；输入 TF 删除原 map→odom，保留 odom→base 和静态雷达外参。没有运行串口、底盘、硬件雷达驱动，也没有下发实车运动命令。

测量方法：以首帧两个长墙段拟合参考直线；使用相同编码器预测选择相同墙点，再计算各自 SLAM 修正后的点到参考直线距离。它衡量扫描间一致性，不能等同于卷尺测得的地图绝对精度。墙可能不完全笔直、数据关联仍有误差。

| 数据 | 处理帧数（原/新） | 较差墙段 RMS（原→新） | 较差墙段绝对偏差 P95（原→新） |
|---|---:|---:|---:|
| 本次实车转弯原始时间记录 | 53 / 53 | 3.32→2.19 cm | 7.01→4.40 cm |
| 产生重影的历史扫描 | 200 / 200 | 第一墙段 5.16→3.64 cm；第二墙段 3.81→3.08 cm | 第一墙段 11.34→6.76 cm；第二墙段 7.41→5.49 cm |

历史扫描从 `.data` 导出原始量测与编码器位姿，重建时人为提供 0.2 s 的时间间隔。原数据未保存每帧真实采集时间，因此这项验证针对扫描匹配/地图一致性，不能检验历史时延或运动畸变。原参数重建的最后 map→odom 与保存图相近（航向相差约 0.2°），支持回放有效。

`compare_wall_consistency.py` 执行断言：两组回放的帧数必须一致，新参数的第二墙段 RMS 和 P95 必须改善。四个回放都有实际地图与保存的位姿图，未以节点启动成功代替验证。

## 应用与重测

修改写入磁盘，当前运行节点仍使用启动时加载的旧参数。需要退出原建图终端，等待整套节点退出，再从空地图重新建图。既有地图中的错误墙线不会因为更改参数立即消失。

终端 A：先 Ctrl+C，等待回到 shell 提示符，然后运行：

```bash
"/home/asuka/Desktop/college-level competition/xiaoche-ros1.sh" \
  roslaunch maze_bridge slam_toolbox_build_map.launch \
  port:=/dev/ttyUSB0 \
  max_v:=0.10 max_w:=0.25 \
  use_camera:=false show_rviz:=true
```

用手柄低速行驶同一段直道，再转弯并返回观察同一面墙。检查实时激光与地图边缘是否保持贴合、墙边是否再次分叉；应分别观察右转和左转。若仍有明显重影，保留原始 scan/odom/TF 记录并核对雷达外参、扫描期间运动畸变和轮胎打滑，不能继续仅凭画面改轮距。

测试完成后，在另一个终端保存新地图：

```bash
"/home/asuka/Desktop/college-level competition/xiaoche-ros1.sh" \
  rosrun map_server map_saver \
  -f /workspace/xiaoche/maps/competition_map_slam_fixed_20261007 \
  map:=/map
```

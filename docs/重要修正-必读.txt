1️⃣ 终点位置会变化

   → 意味着每次比赛，终点位置都不同！
   → 固定轨迹（教学记录）根本不能用

2️⃣ 动态障碍物会出现
   "动态障碍物在机器人建图完成后加入，同时动态障碍物的位置在每次任务开始之前
    随机变化一次"

   → 意味着有新的障碍物会在路上挡住你！
   → 预设的轨迹会撞到这些新障碍物

3️⃣ 结论
   ✗ 教学记录方案会在比赛中100%失败
   ✓ 只有SLAM建图+自主导航才能应对这些变化


【现在的正确方案】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【第一圈：建图（6-8分钟）】
$ roslaunch maze_bridge gmapping_build_map.launch show_rviz:=true

你的操作：
  1. 用遥控或手柄让小车走遍整个迷宫
  2. Gmapping实时扫描环境，生成地图
  3. 地图显示在RViz中（绿色=开放，黑色=障碍）
  4. 完成后停止程序

【第二圈：导航（5分钟以内）】
$ roslaunch maze_bridge navigation_stack.launch mode:=navigation

系统自动做的：
  1. 加载已建立的地图
  2. AMCL定位小车位置
  3. move_base进行自主导航规划

你的操作：
  1. 在RViz中点击"2D Nav Goal"工具
  2. 点击地图上的目标点（根据本次比赛的终点位置）
  3. 小车自动导航到该点
  4. 自动避开所有障碍物（包括新加入的动态障碍物）

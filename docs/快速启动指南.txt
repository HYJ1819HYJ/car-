【问题症状】
  ✗ RViz出现 "Failed to save" 错误
  ✗ 无法保存地图文件
  ✗ gmapping无法启动或地图不出现

【快速修复 - 3步骤】

1️⃣  准备环境
   $ mkdir -p ~/.ros
   $ chmod 777 ~/.ros

2️⃣  编译项目
   $ cd ~/xiaoche
   $ catkin_make -j4

3️⃣  启动建图（二选一）

   方案A - 一键启动（推荐）:
   $ ./build_map.sh

   方案B - 手动启动:
   $ source devel/setup.bash
   $ roslaunch maze_bridge gmapping_build_map.launch

【建图监控】

实时查看地图发布:
   $ rostopic hz /map

检查雷达数据:
   $ rostopic echo /scan | head -5

查看所有节点:
   $ rosnode list

【常见问题排查】

问题: RViz黑屏或无地图显示
→ 解决: rostopic hz /map 检查地图发布

问题: "Permission denied" 错误
→ 解决: sudo usermod -a -G dialout $USER && newgrp dialout

问题: 无法找到 /dev/ttyUSB0
→ 解决: lsusb 检查硬件连接，然后重启udev

问题: gmapping输出"nan"坐标
→ 解决: 检查TF树 - rosrun tf view_frames

【关键概念】

map_saver: 监听 /map 话题并自动保存地图文件
gmapping: 使用激光雷达进行实时SLAM建图
RViz: 3D可视化工具，实时显示建图过程

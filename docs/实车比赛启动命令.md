# 实车比赛启动命令

在本机交互终端进入仓库。比赛使用 ROS1 Noetic Docker 镜像。

```bash
cd '/home/asuka/Desktop/college-level competition/xiaoche'
export LAKIBEAM_WS="$PWD/outputs/competition-lidar-ws"
export FIELD=match-01
bash tools/competition_terminal.sh prepare
```

雷达网口应有 `192.168.198.1/24`。本机可用 `ip -br addr show enp0s31f6` 检查，必要时执行 `nmcli connection up 'LakiBeam-RJ45' ifname enp0s31f6`。

## 1. 建图和保存

```bash
bash tools/competition_terminal.sh map "$FIELD"
# 推车完成建图，回到起点框，按发车方向摆正并停稳后执行下一行
bash tools/competition_terminal.sh save "$FIELD"
```

`save` 在 `outputs/competition-fields/$FIELD/` 保存 `map.yaml`、`map.pgm` 和 `start_pose.json`。起点周围 0.25 m 必须是已建图的自由空间。用已有场次地图时，把 `FIELD` 设置为对应的场次名称，并复现记录的起点位置和朝向。

## 2. 常驻备赛

```bash
bash tools/competition_terminal.sh ready "$FIELD"
```

`ready` 每场执行一次。它预热雷达、相机、云台、定位和导航。可用 `bash tools/competition_terminal.sh status "$FIELD"` 查看待命状态。

## 3. 第一轮发车

```bash
bash tools/competition_terminal.sh go "$FIELD"
```

发令前运行 `go`，等待终端显示 `[READY]`。脚本自动复位起点定位、清除动态代价地图并开始本轮录包。终端会列出待命缺失项。车体停稳后若定位仍偏离起点超过 0.30 m，脚本会自动复位。发车前可按 **r** 立即复位起点并清图。裁判发令后，按一次 **Enter** 或 **空格**。终端显示探索、接近、入库和完成状态。看到静止计时满 **3 秒** 后，按 **Ctrl+C** 结束本轮并封口录包。

## 4. 第二、三轮

确认终端已回到 `IDLE`、底盘目标速度归零。弹出 `PE14`，推回起点摆正后按下 `PE14`。裁判换完障碍和终点后，重复运行同一条命令，等 `[READY]` 后按 **Enter** 或 **空格**。

```bash
bash tools/competition_terminal.sh go "$FIELD"
```

每轮录包位于 `outputs/competition-fields/$FIELD/bags/attempt-*`。整场结束后再执行 `bash tools/competition_terminal.sh stop "$FIELD"` 关闭常驻导航。运行日志可用 `docker logs -f car-competition` 查看。

导航巡航上限默认 1.00 m/s、1.00 rad/s。末端视觉控制上限默认 0.30 m/s、0.50 rad/s。终点由行进间的蓝纸观测定位。动态障碍由 `move_base` 规划绕行，连续三帧雷达确认短距通道净空后才交接给末端控制。

## 模型与坐标

原文件：`/media/asuka/副盘/SW/院赛小车/轮毂小车.STL`。保留原件，将相同内容复制到 `models/wheel_hub_car_mm.stl`，SHA256 为 `caa9c12b9f54b743313457f2897b3247db29298ac01474ddc97b1c40797f7e0d`。SLDPRT 原件未修改。

用户确认：建模单位是毫米；小万向轮所在的圆弧端为车头；模型以外少量急停按钮的突出部分按用户明确要求不加入轮廓。

模型包含 80,316 个三角面，原始 XYZ 范围为 `[0,0,491]` 至 `[500,490,766.2288208]` mm，外包尺寸约 500×490×275.229 mm。Z 原点不在地面；二维碰撞仅使用完整模型的 XY 投影，不把 CAD Z 偏置解释成地面高度，也未据此生成三维 URDF 位姿。

通过两侧驱动轮同轴截面确定模型中的轴线 X≈151.7208 mm，两侧对称中心 Y=245 mm。这个 X 偏移与旧车尾距离 151.7 mm 基本一致。转换采用：

```text
base X = (CAD X - 151.7208) × 0.001
base Y = (CAD Y - 245.0) × 0.001
```

模型实际最大宽度为 490 mm，原矩形配置为 480 mm；新轮廓保留了轮胎的额外宽度，没有为减小碰撞范围把整个模型缩窄。雷达与相机外参、有效轮径/轮距和编码器方向均未改变。

## 二维轮廓生成

完整投影的凸包有 130 个顶点。使用 24 个方向的支撑半平面求交形成外包多边形，包含全部 STL 投影点；每个支撑距离额外增加 1 µm 防止浮点舍入切入模型。保留全部轮胎、车体边沿，但没有利用凸包内部的凹陷或孔洞。

- 完整投影凸包面积约 0.202911 m²。
- 24 边形面积约 0.206335 m²。
- 原矩形面积为 0.240000 m²。
- 新轮廓前沿约 0.348280 m，后沿约 -0.151722 m，半宽约 0.245001 m。
- 不含安全余量的最大转动半径约 0.349827 m，原矩形约 0.422981 m；这是绕当前驱动轮轴中心的几何上界，不能单独保证某处弯道可通过。

俯视对比图：`../outputs/stl_footprint_20261014/footprint_comparison.png`。转换工具：`tools/stl_to_footprint.py`；生成配置：`src/maze_bridge/config/footprint_stl.yaml`。例如从项目根目录重新生成：

```bash
python3 tools/stl_to_footprint.py models/wheel_hub_car_mm.stl \
  --units mm --origin-xy 151.7208 245.0 \
  --output-yaml src/maze_bridge/config/footprint_stl.yaml \
  --output-json outputs/stl_footprint_20261014/footprint_regenerated.json
```

转换工具需要 NumPy、SciPy 和 PyYAML，在宿主机已存在；ROS 节点运行时不读取 STL，也不依赖这些 Python 几何库。

## 接入的碰撞判断

单个 YAML 使用同一组顶点及别名覆盖全局/局部代价地图、TEB polygon 模型、serial_bridge 和 scan_self_filter。平滑全局规划器从 costmap 读取完整多边形，继续进行凸多边形与障碍栅格的扫掠检查。

独立串口保护新增可选 `~footprint`，采用完整凸多边形和到边界的距离检查。保留矩形算法用于回退。前后净空也改为在障碍物所在侧向位置查询实际多边形截面，避免仍从外包矩形的最远车头计算距离。快速外包框只用于排除明显远离车体的点，最终判定仍使用多边形。

雷达过滤同步使用同一多边形，保留位于原矩形角部、实际车体之外的障碍回波，继续去掉实际车体及过滤余量内的回波。

3–64 个顶点、有限坐标、非退化凸多边形、轴心在轮廓内等条件在节点启动时检查。非法模型在打开串口之前终止，不静默切换到另一种形状。轮廓仅在启动时加载；没有实现行驶中热更新。

现有各层安全 padding、前后停车阈值、预测时长、雷达超时、指令超时和自主倒车限制保留。各层 margin 的计算方式不同，不能简单相加或等同于保证的侧向间隙。

临时回退到原矩形：在原启动命令末尾添加 `use_stl_footprint:=false`。不要使用空字符串参数作为回退：本次实测 ROS launch 命令行会忽略空值，已改为明确的布尔开关。切换会清理碰撞消费者的私有参数命名空间，避免同一 master 上遗留上次的多边形。

原始代码和 launch 备份位于 `../outputs/stl_footprint_20261014/before/`。如需持久回退，先将四个入口的 use_stl_footprint 默认值设为 false；多边形支持代码可保留，未提供 ~footprint 时沿用原矩形。若恢复文件，应只恢复本次改动，避免覆盖原有和后续的其他修改。

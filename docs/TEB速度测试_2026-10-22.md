# asuka-main TEB 仿真速度测试

当前加载的基础参数为 `src/maze_bridge/launch/teb_local_planner_params_v2.yaml`；原参数归档为 v1 且不加载，详见 [TEB 参数版本](TEB参数版本_2026-10-22.md)。

DWA 修改单独保存在 `asuka_dwa`，提交 `d925821`。`asuka-main` 保留 TEB，并为仿真补齐 3 m/s、1 rad/s 的速度上限配置；本次配置纳入 2026-10-25 的提交范围。

## 范围

- 局部规划保持 `maze_smooth_planner/ForwardTebLocalPlanner`，内部使用 TEB。
- 仿真启动参数 `max_nav_v/max_nav_w` 同时传给 TEB 和仿真安全门；Stage 世界及生成模板支持 3/1。
- 安全门复用 DWA 分支已经通过测试的速度限制实现，保留近障减速、完整车体预测、禁止倒车和超时停车。加速度与实车入口默认设置保持原值。
- 这里的 `01_open` 来自 `asuka-main` 的旧版新增箱体场景，箱位和 DWA 分支的搬移箱体场景不同，不能作为严格同场景算法对照。

## 终端 1：启动

先退出原仿真，等待 Stage、RViz 和旧 master 退出，再执行：

```bash
cd '/home/asuka/Desktop/college-level competition/xiaoche'
./start-competition-sim.sh \
  scenario:=01_open \
  demo:=false \
  show_rviz:=true \
  max_nav_v:=3 \
  max_nav_w:=1
```

地图和定位就绪后，在 RViz 使用 **2D Nav Goal** 指定目标。测试使用独立 master 11329，不启动实车串口或真实雷达。3/1 是速度上限；实际速度仍受加速度、轨迹和独立安全门约束。

## 终端 2：核对参数并查看实际速度

```bash
R1='/home/asuka/Desktop/college-level competition/xiaoche-ros1.sh'
"$R1" env ROS_MASTER_URI=http://127.0.0.1:11329 \
  rosparam get /move_base/base_local_planner
"$R1" env ROS_MASTER_URI=http://127.0.0.1:11329 \
  rosparam get /move_base/TebLocalPlannerROS/max_vel_x
"$R1" env ROS_MASTER_URI=http://127.0.0.1:11329 \
  rosparam get /move_base/TebLocalPlannerROS/max_vel_theta
"$R1" env ROS_MASTER_URI=http://127.0.0.1:11329 \
  rostopic echo /odom/twist/twist
```

前三项预期为 `maze_smooth_planner/ForwardTebLocalPlanner`、`3`、`1`。最后一项中 `linear.x` 是虚拟车的里程计前进速度，`angular.z` 是角速度。

如需分别检查规划输出与安全门输出，可在另开的终端查看 `/simulation/nav_cmd_vel` 与 `/simulation/cmd_vel`，二者不等同于实际里程计速度。

结束时先在测速终端按 Ctrl+C，再在启动终端按 Ctrl+C。测试尚未覆盖 3/1 上限下的完整路线通行。

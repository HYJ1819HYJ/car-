# 导航定位与定点余量（2026-10-15）

本版解决静止时定位不继续收敛、中心点路径转弯时车身无法通过，以及 TEB 小幅倒车请求被底盘安全层整条拒绝的问题。用户已在现场确认本版可用。

## 配套文件

- `maps/competition_map_20261015_final.yaml` / `.pgm`：今天重新采集并保存的地图，分辨率 2.5 cm。
- `maps/competition_map_20261015_final_corner_clearance.yaml` / `.pgm` / `.json`：中间隔板定点余量及与原地图配对的哈希。
- `src/maze_bridge/config/corner_clearance_20261015.yaml`：两个选择区域及额外余量。

原始地图图像保留不变。源地图和余量地图使用相对图像路径，便于在其他电脑加载。本仓库包含 ROS1 上位机代码，STM32 固件和 LakiBeam 厂商驱动仍在独立工程中。

## 启动导航

在 ROS Noetic 环境内编译，并 source 雷达厂商工作空间和本工程；不要同时运行建图与导航。Ubuntu 24.04 宿主机使用 Noetic 容器，以下 ROS 命令在容器内运行。

```bash
source /opt/ros/noetic/setup.bash
source ~/LakiBeam_ws/devel/setup.bash
cd ~/xiaoche
catkin_make -DCMAKE_BUILD_TYPE=Release -j4
source devel/setup.bash

roslaunch maze_bridge navigation_stack.launch \
  mode:=navigation \
  map_file:="$(pwd)/maps/competition_map_20261015_final.yaml" \
  port:=/dev/ttyUSB0 camera_device:=/dev/video4 \
  max_v:=0.10 max_nav_v:=0.10 max_nav_w:=0.25 \
  corner_clearance:=true forward_only_local_planner:=true \
  use_stl_footprint:=true safety_enable:=true \
  enable_blue_autonomy:=false use_gimbal:=false show_rviz:=true
```

请按实际工作空间位置调整 `cd` 和 source 路径。Docker 中本工程位于 `/workspace/xiaoche`，雷达工作空间位于 `/home/rosdev/LakiBeam_ws`；容器设备映射也需先确认。两个相同 CH341 转串口的 by-id 标识可能相同，不能根据 ttyUSB 编号猜底盘归属。重新插拔后，若无编码器反馈，应退出节点并刷新 Docker 设备绑定。

RViz 打开后，先用 **2D Pose Estimate** 对准小车真实位置和朝向。等待激光与地图重合后再选 **2D Nav Goal**。静止更新节点只请求 AMCL 重新利用激光观测，不发送速度或导航目标。

## 定点余量

只选择以下地图区域内的真实占据格，并在其外添加 5 cm 规划余量：

| 区域 | 地图坐标中心（米） | 选择半径 |
| --- | --- | --- |
| 中间隔板端头 | `(1.3125, -0.50)` | 0.15 m |
| 中间隔板内侧拐角 | `(0.3125, -0.5125)` | 0.15 m |

两处余量分别加入全局和局部代价地图。全局膨胀半径 0.40 m、衰减系数 5；局部膨胀半径 0.10 m、衰减系数 7。真实 24 点车身轮廓约宽 49 cm，防撞 padding 2 cm、前方停车阈值 8 cm 均保留。

本地图默认开启定点层。新地图默认关闭，需按新地图坐标重新选区，不能复用旧坐标。校验节点会拒绝源地图、掩膜图像或坐标元数据不匹配的文件。

调整本图选区后，在提供 NumPy、SciPy、Pillow、PyYAML 的 Python 环境重新生成：

```bash
python3 tools/generate_corner_clearance_map.py \
  --map maps/competition_map_20261015_final.yaml \
  --config src/maze_bridge/config/corner_clearance_20261015.yaml \
  --output maps/competition_map_20261015_final_corner_clearance
```

生成后退出旧导航，再启动新节点。仅关闭定点余量时，启动参数设为 `corner_clearance:=false`。

## 前进策略与转向

发行版 TEB 的动态参数限制使其仍可能请求小幅倒车。底盘独立安全层继续禁止自动倒车。

`ForwardTebLocalPlanner` 遇到倒车请求时，另行检查未来 0.60 秒的原地转向。只有局部代价地图新鲜、真实车身加 2 cm 余量的整个旋转扫掠可通过时才发布零线速度转向；否则返回失败并重规划。底盘仍用实时激光再次检查，不直接执行被拒绝倒车弧线的角速度。

诊断话题：`/move_base/ForwardTebLocalPlanner/diagnostics`。恢复原 TEB 可使用 `forward_only_local_planner:=false`，但原来的倒车拦截可能重新出现。全局规划器的原回退开关仍为 `smooth_global_plan:=false`。

## 颜色重叠的含义

膨胀半径从障碍栅格向外计算。车边离墙 25 cm、全局软膨胀 40 cm 时，车身轮廓可以与外围代价颜色重叠约 15 cm。是否碰撞由真实障碍/规划余量格和整车扫掠检查决定；彩色区域并非全部都是禁入格。

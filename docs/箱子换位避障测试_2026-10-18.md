# 箱子换位避障：重新建图与现场测试

本次场地已经变化，旧图导航已停止。采用“固定墙/隔板底图 + 实时箱子障碍”的方式。**建图前移开可移动箱子，地图保存并退出建图后再放入箱子。**不要把箱子画成固定墙角；本版不会根据几何猜测去删除真实墙体。

## 终端一：启动固定结构建图

先把小车放在起点，移开可移动箱子，底盘和雷达上电。

```bash
cd "/home/asuka/Desktop/college-level competition"
nmcli connection up LakiBeam-RJ45
./refresh-peripherals.sh
./xiaoche-ros1.sh roslaunch maze_bridge slam_toolbox_build_map.launch \
  port:=/dev/ttyUSB0 baud:=115200 \
  max_v:=0.10 max_w:=0.25 \
  use_camera:=false use_stl_footprint:=true \
  safety_enable:=true show_rviz:=true
```

保持这个终端运行。刷新外设会重建容器，只在启动建图前执行，不在建图中执行。

## 终端二：键盘控制建图

```bash
cd "/home/asuka/Desktop/college-level competition"
./xiaoche-ros1.sh rosrun teleop_twist_keyboard teleop_twist_keyboard.py \
  _speed:=0.10 _turn:=0.25 _repeat_rate:=10.0 _key_timeout:=0.4
```

焦点放在本终端：`i` 前进，`j` 左转，`l` 右转，`k` 停车。绕行并观察地图墙体是否完整；结束后按 `k` 停车。

## 终端三：保存地图

终端一必须仍在建图。


看到 `Done` 后，终端二按 `Ctrl+C` 退出键盘控制，再在终端一按 `Ctrl+C` 退出建图，等待整套节点退出。此文件名在准备本说明时不存在，不覆盖旧场地图；再次重建时请保存为新名字并同步修改下一步的 map_file。

## 终端一：启动新图导航

地图已保存、建图节点已退出后执行。无需再刷新外设。

```bash
cd "/home/asuka/Desktop/college-level competition"
./xiaoche-ros1.sh roslaunch maze_bridge navigation_stack.launch \
  mode:=navigation \
  map_file:=/workspace/xiaoche/maps/competition_map_20261018_dynamic.yaml \
  port:=/dev/ttyUSB0 baud:=115200 camera_device:=/dev/video4 \
  max_v:=0.10 max_nav_v:=0.10 max_nav_w:=0.25 \
  corner_clearance:=true corner_extra_clearance:=0.05 corner_scope:=main_walls \
  forward_only_local_planner:=true use_stl_footprint:=true \
  safety_enable:=true enable_blue_autonomy:=false use_gimbal:=false show_rviz:=true
```

系统自动按新图生成固定墙角的 5 cm 保护。先用 RViz `2D Pose Estimate` 设置当前实车位置和朝向，确认激光与墙体重合，再开始导航。

## 放箱子测试

1. 先无箱设置一次空旷目标，确认新图定位与导航正常。
2. 小车停车后，把箱子放在原路径旁/路径中，留出足够的绕行空间。等雷达和代价地图显示箱子，再设置箱子另一侧的目标；应重新选路绕行。通道完全堵死时应停车，不能要求穿过箱体。
3. 小车停车后，将箱子从 A 搬至 B。雷达能重新扫通 A 时，A 的实时障碍应消失，B 被标记；重新设置目标测试。小车看不到 A 时，保留旧观测是有意的，不能把“没看见”当“已经空了”。
4. 固定墙角保护应一直保留。测试中不要手动调用 `/move_base/clear_costmaps` 抹掉附近盲区中的箱子观测。

可在另一个终端检查新避障扫描流（检查后 `Ctrl+C` 退出频率显示）：

```bash
cd "/home/asuka/Desktop/college-level competition"
./xiaoche-ros1.sh rostopic hz /scan_obstacles
```

可选：导航启动后开启 10 分钟只读录像，便于检查现场行为，不会发送运动指令：

```bash
cd "/home/asuka/Desktop/college-level competition"
./xiaoche-ros1.sh python3 tools/record_navigation_session.py --minutes 10
```

## 本次修改与已完成验证

- `/scan` 保留原来的建图/定位行为；新增 `/scan_obstacles` 给全局和局部障碍层。车身自反射转为 NaN，不再伪装成无穷远空路；真实无回波的正无穷和外部障碍点保持原值。
- 自动恢复清障保留小车周围 4 m 方形内的障碍观测，覆盖当前完整局部窗口；不再因恢复动作忘记近处盲区中的箱子。真实清障射线仍能释放已经移开的箱位。该区域是清障保留窗口，不是增大障碍膨胀。
- 记录工具新增避障扫描流及固定角保护图。车身轮廓、独立底盘防撞、5 cm 固定角余量、自主不倒车和速度限制保持原值。
- Noetic 构建、真实过滤节点的 ROS 回归测试通过。无网络、无设备隔离测试中，新箱子使路径由 80 点改为 101 点，搬走后恢复 80 点；盲区观测由旧方式的 0 格误清空改为保留 27 格。自动恢复前后仍为 27 格，真实空路扫描后为 0 格。恢复对照使用的两个不可达目标仅发到隔离 ROS，输出非零速度数为 0；没有向实车发送目标。
- 以上不是实车箱子换位验收，实际结果以本次重新建图后的现场测试为准。旧图里已画入的箱体仍不会自动从静态层消失；本次通过无箱基图避免这个问题。

原理参考：[ROS 清障恢复实现](https://raw.githubusercontent.com/ros-planning/navigation/noetic-devel/clear_costmap_recovery/src/clear_costmap_recovery.cpp)。本地验证原始记录在 `outputs/moved_box_fix_20261018/`。

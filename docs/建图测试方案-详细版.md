# 小车迷宫竞赛建图测试方案 (详细版)

## 📌 比赛规则解读

根据《圣光机学院第五届大学生智能机器人竞赛》规则，你的小车的作战方案是：

### 第一圈：人工控制（教学记录）
- **控制方式**：蓝牙手柄遥操作小车
- **任务**：手动带小车走过整个迷宫，记录轨迹
- **记录内容**：每个时间点的速度指令 (v, w) 保存到 CSV 文件
- **保存路径**：`~/.ros/maze_teach.csv`

### 第二圈：自主复现（教学重演）
- **控制方式**：自动重放第一圈的轨迹
- **任务**：小车自动按照记录的速度指令走迷宫
- **安全保护**：激光雷达实时监测，遇到障碍物自动停车

### 🚨 重要区别
- **建图（Gmapping）** ← 这是用来做导航研究的，**不是比赛必需的**
- **教学记录/复现** ← 这是**比赛实际使用的方法**

## 🔧 建图在你的项目中的作用

### 情况A：你选择使用Gmapping建图（可选）
- **目的**：生成完整的迷宫地图
- **用途**：用于导航算法研究、路径规划
- **比赛中的作用**：**零分但可以加分项**（参见规则第8条特等奖）
- **需要的时间**：20分钟内的建图时间被计入总时间

### 情况B：你继续使用教学记录/复现（推荐）
- **优势**：简单可靠，不依赖建图精度
- **适合**：像你这样有相对固定的迷宫环境
- **比赛中的作用**：**主要得分方式**

## 📋 完整的比赛日流程

### 时间限制
- **总时间**：20分钟（从裁判说"开始建图"开始计时）
- **建图时间**：建图完成后，固定障碍物就不变了
- **3次导航机会**：每次最多5分钟，选最优成绩

### 具体流程

#### 📍 阶段1：准备阶段（建图）
```
20分钟倒计时开始
裁判：" xx号队伍，比赛开始，请开始建图 "

选手操作：
1. 一键启动小车（按键/按钮/命令）
2. 用手柄或自动算法遥控小车在场地内走动
3. 建图程序实时创建地图
```

#### 📍 阶段2：第一次导航尝试
```
建图完成后，会加上动态障碍物

裁判：" xx号队伍，第1次导航任务，计时开始 "

选手操作：
1. 设定终点坐标给小车
2. 小车自主导航到终点
3. 到达终点的标准：
   - 2/3车体在终点区域内
   - 保持3秒不动
   - 识别到蓝色A4纸标志
```

#### 📍 阶段3：失败处理
```
如果5分钟内没到达或主动放弃：
- 记录几何中心到终点的直线距离
- 选手可以进行第2、3次尝试

每碰到一个障碍物，加时3秒（惩罚）
```

## 🚀 建议的测试顺序

### 场景1：模拟比赛现场环境（无障碍物）

#### 第1天：验证基础功能
```
1. 启动手柄教学记录
   $ roslaunch maze_bridge teach_teleop_complete.launch
   
2. 手动用手柄遥控小车
   - 前进3米
   - 左转90度
   - 后退2米
   - 右转90度
   
3. 验证录制成功
   $ cat ~/.ros/maze_teach.csv | wc -l  # 应该有数百行数据

4. 启动复现模式
   $ roslaunch maze_bridge teach_teleop_replay.launch
   
5. 观察小车是否按照相同的轨迹重演
```

#### 第2天：在实际迷宫环境中测试
```
1. 设置迷宫环境（固定障碍物）

2. 启动手柄教学记录
   $ roslaunch maze_bridge teach_teleop_complete.launch
   
3. 用手柄牵引小车走完整个迷宫
   - 避开固定障碍物
   - 尽量找到最快路径
   
4. 停止记录，验证文件大小
   ls -lh ~/.ros/maze_teach.csv
   
5. 启动复现模式
   $ roslaunch maze_bridge teach_teleop_replay.launch
   
6. 验证小车是否能自动走完迷宫
   - 是否能避开障碍物
   - 是否能回到起点或到达终点
```

#### 第3天：添加动态障碍物测试
```
1. 启动手柄教学记录（已有迷宫，无动态障碍）
   $ roslaunch maze_bridge teach_teleop_complete.launch
   
2. 记录迷宫路线
   
3. 启动复现模式
   $ roslaunch maze_bridge teach_teleop_replay.launch
   
4. 在小车运行过程中，在轨迹前方放置临时障碍物
   
5. 验证小车的反应：
   - 激光雷达是否检测到障碍物
   - 小车是否停止或转向
   - 是否触发了安全保护机制
```

## 📈 性能调优建议

### 如果小车在复现时偏离轨迹

**可调参数** (在 teach_teleop_replay.launch 中)：
```xml
<!-- 速度缩放因子（0.0-1.0）, 减小以降低速度 -->
<arg name="replay_speed_scale" default="0.8"/>

<!-- 安全停止距离（米）, 减小以允许靠近障碍物 -->
<param name="front_stop_m" value="0.35"/>
```

### 如果手柄反应延迟

**可调参数** (在 teach_teleop_complete.launch 中)：
```xml
<!-- 增加发送频率（Hz）, 最大50Hz -->
<param name="tx_hz" value="50.0"/>

<!-- 减少超时时间（ms）, 默认300ms -->
<param name="timeout_ms" value="300"/>
```

## ❌ 常见问题及解决

### 问题1：手柄无法控制小车
```
原因：手柄设备不存在
解决：
  ls /dev/input/js0           # 检查手柄
  sudo systemctl restart bluetooth  # 重启蓝牙
  sudo bluetoothctl scan on   # 扫描手柄
```

### 问题2：轨迹文件为空或太小
```
原因：手柄没有正确输入信号，或记录时间太短
解决：
  - 确保按住L1按钮
  - 确保摇杆完全移动（不要在死区）
  - 记录时间至少30秒以上
```

### 问题3：复现时小车不动
```
原因：轨迹文件格式不对，或启动了错误的launch
解决：
  cat ~/.ros/maze_teach.csv | head -5  # 检查格式
  rosnode list | grep teach_repeat    # 检查进程
```

### 问题4：小车在复现时撞到障碍物
```
原因：障碍物位置变了（这在比赛中会发生）
解决：
  - 减少速度缩放因子
  - 增加激光雷达的避障距离
  - 确保安全模式启用
```

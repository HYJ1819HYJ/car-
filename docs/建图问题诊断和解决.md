# 小车建图问题解决方案

## 📍 问题分析

根据截图分析，当前出现的错误：
```
Failed to save
Failed to open /gis/playing/gmapping.rviz for writing
```

### 根本原因
1. **RViz配置文件保存路径无权限** - `/gis/playing/` 目录不存在或权限不足
2. **地图保存目录未创建** - `~/.ros` 目录可能不存在或权限不足
3. **gmapping未正确发布地图** - map_saver无法获取地图话题数据

---

## 🔧 立即修复步骤

### 第1步：创建并赋予权限
```bash
# 创建地图保存目录
mkdir -p ~/.ros
chmod 777 ~/.ros

# 验证权限
ls -ld ~/.ros
# 应该显示: drwxrwxrwx
```

### 第2步：清理旧的ROS进程
```bash
# 杀死所有ROS进程
killall -9 roscore rosmaster roslaunch gzclient gzserver 2>/dev/null || true
sleep 2

# 检查是否完全清理
ps aux | grep -E "ros|gazebo" | grep -v grep
```

### 第3步：验证硬件连接
```bash
# 检查串口
ls -la /dev/ttyUSB*

# 检查雷达USB设备
lsusb | grep -i lidar

# 如果看不到设备，检查权限
sudo usermod -a -G dialout $USER
sudo usermod -a -G plugdev $USER
# 重新登录或运行: newgrp dialout
```

### 第4步：使用新的建图脚本
```bash
cd ~/xiaoche
./build_map.sh
```

## 📋 为什么会出现"Failed to save"错误？

### 原因分析

| 原因 | 症状 | 解决方案 |
|------|------|--------|
| 目录不存在 | `/gis/playing/` 报错 | 使用 `~/.ros` 作为保存路径 |
| 权限不足 | "Permission denied" | `chmod 777 ~/.ros` |
| gmapping未运行 | map_saver获取不到 /map | 检查gmapping是否启动成功 |
| 雷达无数据 | gmapping无法建图 | 检查 `/scan` 话题是否发布数据 |
| 软件冲突 | RViz频繁重启 | 杀死旧进程，重新启动 |

### 调试命令

```bash
# 查看活跃的ROS话题
rostopic list

# 检查/map话题是否发布
rostopic hz /map

# 检查/scan话题数据
rostopic echo /scan | head -20

# 查看gmapping节点状态
rosnode info /slam_gmapping

# 实时查看ROS日志
rqt_console
```

### 检查清单

- [ ] ROS节点启动无错误
- [ ] RViz能够显示地图 (`/map` 话题)
- [ ] 雷达数据可见 (`/scan` 话题)
- [ ] 地图文件已保存：`ls ~/.ros/maze_map.*`
- [ ] 可以加载保存的地图：
  ```bash
  rosrun map_server map_server ~/.ros/maze_map.yaml
  ```

### 正常建图的征象

1. **RViz显示内容**
   - 见到灰色栅格
   - 见到黄色激光点
   - 见到正在扩展的地图区域

2. **ROS话题数据**
   ```bash
   $ rostopic hz /map
   average rate: 0.50
   # 表示每2秒发布一次新地图
   
   $ rostopic hz /scan  
   average rate: 25.00
   # 表示雷达正常运行
   ```

3. **日志输出** (没有错误)
   ```
   [slam_gmapping] Processing spin #123
   [map_saver] Map saved to ...
   ```

## 🆘 常见问题排查

### Q: RViz显示为黑屏或无地图
**A**: 
```bash
# 检查/map话题是否存在
rostopic list | grep map

# 重启gmapping
rosnode kill /slam_gmapping
sleep 2
rosnode list  # 应该能看到它重新启动
```

### Q: "Failed to open /dev/ttyUSB0"
**A**:
```bash
# 检查串口权限
ls -la /dev/ttyUSB0

# 添加当前用户到dialout组
sudo usermod -a -G dialout $USER
newgrp dialout  # 立即生效，无需重启
```

### Q: gmapping输出 "nan" 或错误的坐标
**A**:
```bash
# 这通常意味着里程计数据有问题
# 检查编码器数据
rostopic echo /wheel_encoder | head -20

# 检查TF树是否正确
rosrun tf view_frames
# 将生成 frames.pdf，检查坐标系关系
```

### Q: 地图文件保存失败
**A**:
```bash
# 查看map_saver的完整输出
rosnode info /map_saver

# 手动保存地图
rosrun map_server map_saver -f ~/.ros/manual_save_map

# 检查文件权限
ls -la ~/.ros/maze_map.*
```
